The travel poster of NIMBARA — a place that isn't there. An island
where the sky falls into the sea: a luminous waterfall pours out of a
low golden cloud straight down into a turquoise bay, a whitewashed
cliff village climbs the rock on the right, and a single sailboat
drifts on the calm water below the falls. Warm sunset gold, teal sea,
vintage poster grain — one impossible landmark, one clear promise of
a stay.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, Pillow) draws the 1024x1024 poster to
`/output/entry.png` — it crops the base painting square on the
waterfall, frames it in cream like a vintage poster, and sets the
name NIMBARA in huge cream serif with the tagline "WHERE THE SKY
FALLS INTO THE SEA" beneath it. The base painting is generated for
this entry, kept as `base.jpg`. No network, no randomness: two runs
produce the same bytes.
